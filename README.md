# BlackBox-NFS-Export-Tools
A collection of tools that facilitate the conversion process in BlackBox NFS games.

## Auto CFG

Auto CFG is a programme that quickly generates the configuration file for an NFS mod. Simply load your .obj and .mtl files into the programme, adjust the shaders and the game, export, and you're done!

### How it works

Auto CFG extracts the data from your .obj/.mtl objects, as well as the materials and textures assigned to them. With all this, it generates a base text that can be used as a configuration file to create a mod.
Obviously, for now, the programme cannot guess the game for which the mod will be used or the shaders; this must be done manually (it is faster to do it from within the programme itself).

## Known errors

None at the moment.

## Texture Manager

Texture Manager is a tool that batch-converts all the textures used by your NFS car to DDS DXTC1/DXTC3; it also allows you to batch-resize them to the desired resolution.

## How it works

Simply adjust each parameter required by Texture Manager and then select a destination folder; the application does the rest.

## Known issues
