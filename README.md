# BlackBox-NFS-Export-Tools
A collection of tools that facilitate the conversion process in BlackBox NFS games.

## Ultimate Car Conversion Tools

UCCT streamlines the entire conversion process by automatically generating the configuration file, creating the VLT script and other useful options, saving around 30 minutes (or an hour on many large projects)

## Texture Manager

Texture Manager is a tool that batch-converts all the textures used by your NFS car to DDS DXTC1/DXTC3; it also allows you to batch-resize them to the desired resolution. (Made by Akino6)

## How it works

Simply adjust each parameter required by Texture Manager and then select a destination folder; the application does the rest.
